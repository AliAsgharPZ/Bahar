# دروازه شاد بهار (Bahar Shad Gateway)

سرویس جانبی پایتون برای اتصال واقعی سامانه بهار به پیام‌رسان **شاد** با کتابخانه غیررسمی [shad-api](https://github.com/HoseanRC/shad-api).

## دو حالت کار شاد در بهار

بهار بدون این سرویس هم کار می‌کند — **شبیه‌سازی داخلی** (INTERNAL):

- مدیر مدرسه در پنل بهار (بخش «شاد») شماره شاد خود را وارد می‌کند، کد تایید ۵ رقمی می‌گیرد
  (در حالت شبیه‌سازی، کد همان‌جا به او نمایش داده می‌شود) و حساب مدرسه متصل می‌شود.
- پیام‌ها (اعتبارنامه کاربران و اطلاع‌های کوتاه) در «صف خروجی شاد» بهار ثبت و
  به‌صورت SENT تحویل می‌شوند — بدون خروج به شبکهٔ واقعی. برای دمو، آموزش و
  ارزیابی سامانه بدون هیچ وابستگی بیرونی.

این سرویس (اختیاری) حالت **دروازهٔ واقعی** (EXTERNAL) را فعال می‌کند:

- اپ اصلی بهار (Next.js) وقتی می‌خواهد رمز عبور کاربران را **واقعاً** با شاد بفرستد، از طریق HTTP با همین سرویس صحبت می‌کند.
- این سرویس با توکن `auth` حساب شاد **مدیر مدرسه** به شبکه شاد وصل می‌شود، شماره موبایل هر کاربر را به شناسه شاد او تبدیل می‌کند و پیام را واقعاً ارسال می‌کند.
- توکن مدیر هیچ‌وقت به مرورگر کاربران نمی‌رسد و در دیتابیس بهار به‌صورت رمزنگاری‌شده (AES-256-GCM) ذخیره می‌شود.
- برای اتصال واقعی، سرویس را اجرا کنید تا در پنل بهار گزینهٔ «اتصال واقعی با توکن شاد» ظاهر شود؛ پس از اتصال با توکن، ارسال‌های آن مدرسه از دروازهٔ واقعی می‌گذرند.

## نصب و اجرا

```bash
cd mini-services/shad-gateway
pip3 install -r requirements.txt
python3 gateway.py
```

سرویس روی `127.0.0.1:8787` اجرا می‌شود (قابل تغییر با متغیر محیطی `SHAD_GATEWAY_PORT`).
اگر آدرس دروازه چیز دیگری است، در فایل `.env` پروژه اصلی بهار این را تنظیم کنید:

```
SHAD_GATEWAY_URL=http://127.0.0.1:8787
```

## توکن حساب شاد مدیر از کجا می‌آید؟

طبق راهنمای رسمی shad-api:

1. روی کامپیوتر وارد [web.shad.ir](https://web.shad.ir) شوید.
2. کلید `F12` یا `Ctrl+Shift+I` را بزنید تا Developer Tools باز شود.
3. به تب **Network** بروید.
4. در شاد یک چت باز کنید یا پیامی بفرستید تا درخواست‌ها ثبت شوند.
5. از لیست درخواست‌ها، درخواستی که دامنه‌اش با `shadmessenger` شروع می‌شود را انتخاب کنید.
6. در تب **Request**، فیلد رشته‌ای `auth` را پیدا کنید؛ همان توکن حساب شماست.

سپس در پنل بهار، مدیر مدرسه از بخش «شاد» این توکن و شماره شاد خودش را وارد می‌کند تا اتصال برقرار شود.

## مسیرهای API

| مسیر | ورودی | خروجی |
|------|-------|-------|
| `GET /health` | — | `{ok: true, version}` |
| `POST /verify` | `{token, phone}` | `{ok, guid, name, phone}` |
| `POST /send` | `{token, phone, first_name, text}` | `{ok, message_id, to_guid}` |

## نکته‌ها

- سرویس فقط روی `127.0.0.1` گوش می‌دهد؛ روی همان سروری اجرا شود که بهار روی آن است.
- شاد برای جلوگیری از اسپم محدودیت نرخ ارسال دارد؛ ارسال گروهی انبوه را با فاصله انجام دهید (پنل بهار خودش صف‌بندی می‌کند).
- خروج از حساب در web.shad.ir ممکن است توکن را باطل کند؛ در این حالت مدیر دوباره توکن می‌گیرد و در بهار جایگزین می‌کند.
