# ربات تلگرام بهار

ربات رسمی سامانه بهار با دسترسی کامل به امکانات (نمرات، حضور غیاب، برنامه، تکالیف، شهریه، اعلان‌ها، فرزندان).

## راه‌اندازی (۳ دقیقه)

1. **ساخت ربات:** در تلگرام به [@BotFather](https://t.me/BotFather) پیام `/newbot` بدهید، اسم و یوزرنیم بدهید و **توکن** را کپی کنید.

2. **فعال‌سازی در بهار:** در سایت بهار با سوپرادمین وارد شوید → «تنظیمات سامانه» → بخش «ربات تلگرام» → توکن را بچسبانید و فعال کنید.

3. **تنظیم این پوشه:**
   ```bash
   cp config.example.json config.json
   # سپس config.json را ویرایش کنید:
   #   api  → آدرس سایت بهار شما (مثلا https://bahar.example.com)
   #   token → همان توکن BotFather
   ```

4. **اجرا:** (Node.js نسخه ۱۸ یا بالاتر)
   ```bash
   node bot.js
   ```

## اتصال کاربران

هر کاربر در سایت بهار → «پروفایل» → «پیوند تلگرام» یک کد می‌گیرد و به ربات می‌فرستد:
```
/start ABCD123
```
از آن لحظه دستورات ربات برایش کار می‌کند.

## دستورات

| دستور | کار |
|---|---|
| /digest | خلاصه امروز |
| /me | پروفایل |
| /grades | نمرات |
| /attendance | حضور و غیاب |
| /schedule | برنامه امروز |
| /assignments | تکالیف |
| /fees | شهریه |
| /notifications | اعلان‌ها |
| /children | فرزندان (والد) |
| /unlink | قطع پیوند |

## اجرای دائمی (سرور لینوکس)

```bash
# با pm2
npm i -g pm2
pm2 start bot.js --name bahar-telegram
pm2 save
```

## نکته امنیتی
توکن ربات را هرگز در گروه‌ها نفرستید. API سایت فقط با همین توکن (هدر `x-bot-token`) پاسخ می‌دهد و بدون آن کاملاً بسته است.
