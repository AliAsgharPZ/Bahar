# Bahar Design Language — v3 (سند زبان طراحی سامانه بهار)

> **مخاطب**: طراحان و توسعه‌دهندگان سامانه.
> **قاعده کلی**: این سند «منبع واحد حقیقت» رابط کاربری بهار است. هر تغییر بصری باید با این سند هم‌خوان باشد.
> **وضعیت**: فقط-خواندنی — نمایش در تنظیمات سامانه برای مدیر کل.

---

## 1. هویت

| ویژگی | مقدار |
|---|---|
| نام محصول | بهار (Bahar) — سامانه جامع مدیریت مدارس |
| استعاره مرکزی | بهارِ کامل: شکوفایی، تازگی، رشد دانش‌آموز |
| زبان طراحی پایه | Meta (Facebook) Design Language — نسخه بازتنظیم‌شده |
| جهت | RTL کامل فارسی (`dir="rtl"`) |
| ارقام | فارسی (۰۱۲۳۴۵۶۷۸۹) در همه رابط‌ها |
| تقویم | شمسی جلالی (Asia/Tehran) |

## 2. پالت رنگ (Bahar Spring)

| نقش | توکن | مقدار | کاربرد |
|---|---|---|---|
| Primary | `--spring` | `#00825E` | دکمه اصلی، لینک فعال، نقطه‌تمرکز |
| Primary Deep | `--spring-deep` | `#005A42` | hover، متن روی روشن |
| Primary Soft | `--spring-soft` | `#7FD6B8` | متن سبز روی تیره |
| Tint | `--spring-tint` | `#E8F0EC` | پس‌زمینه انتخاب/هایلایت |
| Accent | `--blossom` | `#E5548B` | تاکید فصلی، نقطه‌ی ثانویه (کم استفاده شود) |
| متن اصلی | `--ink` | `#0A1E17` | متن بدنه |
| متن فرعی | `--steel` | `#5B6B66` | توضیح، زیرنویس |
| متن کم‌رنگ | `--stone` | `#8A9691` | زمان، placeholder |
| پس‌زمینه | `--background` | `#FFFFFF` | صفحه |
| سطح دوم | `--cloud` | `#F2F4F3` | hover ردیف، چیپ خنثی |
| خط جداکننده | hairline | `1px #DFE3E0` | جداکننده‌های نازک |
| خطری | `--destructive` | `#D93036` | خطا، حذف |
| هشدار | `--amber` | `#B2620F` | وضعیت رو به پایان |
| موفقیت | `--spring` | `#00825E` | تایید، انجام شد |

**قاعده نسبت رنگ**: ۶۰٪ خنثی (سفید/ابر) + ۳۰٪ جوهر/فولاد + ۸٪ سبز بهار + حداکثر ۲٪ صورتی شکوفه.
**ممنوع**: بنفش و نیلی پیش‌فرض Tailwind (indigo/blue) مگر در تمپلیت‌های سایت مدارس که پالت خود دارند.

## 3. تایپوگرافی

| سطح | فونت | وزن | اندازه |
|---|---|---|---|
| Display/هیرو | Arad FD | 800 | 44–64px |
| H1 | Arad FD | 700 | 28–34px |
| H2 | Arad FD | 700 | 20–24px |
| H3/کارت | Arad FD | 600 | 15–17px |
| بدنه | Vazirmatn | 400/500 | 13.5–15px |
| زیرنویس | Vazirmatn | 400 | 11–12px |
| کد/شماره | mono (ui-monospace) | 400 | 11.5px، `dir="ltr"` |

- فونت display: **Arad** (با ارقام فارسی بومی)؛ فونت بدنه: **Vazirmatn**.
- طول خط بدنه حداکثر ~۷۲ نویسه؛ تراز متن فارسی راست است (justify ممنوع در لیست‌ها).
- شماره‌ها و کدملی همیشه داخل `dir="ltr"` با فونت مونو.

## 4. شکل‌ها و فاصله‌ها

| عنصر | مقدار |
|---|---|
| شعاع دکمه/چیپ | کامل (pill / 9999px) |
| شعاع کارت | 20px (b-card)، 16px (b-card-sm)، 28px (b-card-md) |
| ارتفاع دکمه | 44px (استاندارد لمس)، 36px (b-btn-sm) |
| ارتفاع فیلد ورودی | 44px، متن 13.5px |
| شبکه فاصله | مقیاس ۴px (gap: 8/12/16/24/32) |
| پدینگ کارت | 20–24px |
| سایه‌ها | فقط ۲ سطح: b-shadow-card (subtle) و b-shadow-rail (سایدبار/مودال) |
| خط جداکننده | hairline نازک به‌جای border سنگین (زبان Meta) |

## 5. اجزای پایه (کلاس‌های b-*)

- `b-btn` + `b-btn-spring | b-btn-soft | b-btn-ghost | b-btn-danger` + `b-btn-sm` — دکمه‌های pill.
- `b-card / b-card-sm / b-card-md` — سطح‌های کاغذی با گوشه‌های نرم.
- `b-input` — فیلد ۴۴px با حالت فوکوس سبز.
- `b-search-pill` — جست‌وجوی capsule با آیکون.
- `b-pill-tab` + `b-pill-tab-active` — تب‌های فیلتر.
- `b-badge` + `b-badge-spring | b-badge-warning | b-badge-critical` — نشان‌های وضعیت.
- `b-promo` + `b-promo-spring` — نوار پیام سیستمی (بانر تغییر رمز/پلن).
- `b-option` — گزینه انتخابی با حالت انتخاب هاله سبز.
- `bubble-me / bubble-them` — حباب پیام‌رسان (ارسال: سبز؛ دریافت: ابر).
- `b-row` — ردیف جدول با hover ابری.
- `b-pop` — انیمیشن ورود (scale 0.96→1 + fade).
- `b-scroll` — اسکرول‌بار نازک سفارشی.
- `b-only-mobile` / `lg:hidden` — الگوی «منو فقط موبایل».

## 6. حرکت و انیمیشن

| تعامل | حرکت |
|---|---|
| ورود مودال | 180ms ease-out، scale .96→1 |
| hover ردیف/دکمه | 120ms تغییر رنگ فقط |
| انتخاب تب | 150ms پس‌زمینه |
| پیام toast | slide-up 200ms |
| بارگذاری | اسپینر 24px یا اسکلتون ابری |

قاعده: هیچ حرکتی بیش از ۲۵۰ms نیست؛ انیمیشن تزئینی ممنوع؛ prefers-reduced-motion احترام شود.

## 7. آیکون‌گرافی

- کتابخانه: Lucide React — خط ۱.۵px، سبک معماری.
- اندازه استاندارد: 16/18/20/24px.
- آیکون‌های جهت‌دار در RTL باید کلاس `flip-rtl` بگیرند (arrow/send).
- هر آیکون معنی عملیات را می‌رساند؛ آیکون تزئینی بدون معنا ممنوع.

## 8. نوار ناوبری اپ (Shell)

- سایدبار راست دسکتاپ ۲۴۸px؛ موبایل: هدر چسبان + دراور.
- آیتم فعال: پس‌زمینه جوهر عمیق، متن سفید (در دارک: برعکس).
- منوی همبرگری «فقط موبایل» — در دسکتاپ هرگز نمایش داده نمی‌شود.
- نشان شمارنده (badge critical) برای پیام‌های نخوانده.
- بنرهای سیستمی (`b-promo`) بالای محتوا: تغییر رمز اجباری، هشدار پلن.

## 9. دسترسی‌پذیری

- هدف لمس حداقل ۴۴×۴۴px.
- کنتراست متن بدنه ≥ 4.5:1.
- همه دکمه‌های آیکونی `aria-label` فارسی دارند.
- فوکوس کیبورد: حلقه سبز 2px.
- سلسله‌مراتب هدینگ بدون پرش (h1→h2→h3).
- `lang="fa"` و `dir="rtl"` در ریشه سند.

## 10. تمپلیت‌های سایت مدارس

پنج تمپلیت با پالت مستقل (classic/modern/academic/playful/royal) — هر کدام ۲–۳ گزینه رنگ. ساختار بخش‌ها ثابت است؛ مدیر فقط متن، تصویر، رنگ و روشن/خاموش بخش‌ها را کنترل می‌کند. تایپوگرافی همان Arad/Vazirmatn باقی می‌ماند.

## 11. لحن متن (Voice)

- فارسی محترمانه و گرم («شما»)؛ جملات کوتاه.
- پیام موفقیت: «انجام شد» + شرح کوتاه. خطا: علت + راه‌حل.
- اصطلاح فنی به فارسی؛ در پرانتز انگلیسی فقط بار اول.
- ویژگی شاد (Shad) با لحن خنثی و بدون تاکید ویژه توصیف می‌شود.

## 12. چک‌لیست پیش از انتشار

1. `bun run lint` بدون خطا.
2. رندر موبایل 390px بدون سرریز افقی.
3. ارقام همه فارسی؛ تاریخ‌ها شمسی.
4. آیکون‌های RTL فلیپ شده‌اند.
5. حالت تاریک سازگار (متن/کارت/سایه).
6. کارت‌ها هم‌تراز، پدینگ یکنواخت، فوتر چسبان در صفحات کوتاه.
